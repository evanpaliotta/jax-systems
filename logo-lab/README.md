# Jax Systems — Logo Lab

50 review-stage vector symbols and a shared illustrative wordmark. Kimi K3.1 Pro generated five batches of ten single-ink SVG concepts; eight were revisited after a contact-sheet review, and one of those was revisited a second time. All 50 are editable SVGs, not stock artwork or claimed trademark-cleared brand assets. The wordmark is an interface-rendered type treatment, not outlined production artwork; SVG downloads are the symbol alone. Illustrative shirt, cap and sticker previews show approximate placement, not production or embroidery proofs.

No logo, wordmark, tagline or legal rights were approved by this exploration. Similarity to existing logos has not been searched. Before commercial use, check trademark conflicts and have the selected mark/wordmark professionally refined and prepared for production; very small spacing and stitches need a real production test.

The initial design generator `scripts/generate_jax_logos.py` makes paid Kimi API calls and overwrites the reviewed 50 with new samples. It is not a reproducible build of the currently selected review set. `logos.json` is the reviewed source of truth; `logo-data.js` and `marks/NN.svg` are synchronized distribution artifacts. The tests assert exact synchronization. Do not rerun the model generator over user-reviewed work without a deliberate revision plan and fresh paid-call budget.

Feedback is browser-local under `jax-logo-lab-feedback-v1`. Export JSON before switching browser or device; import the JSON on the new browser. This key is separate from the website design gallery's key, so feedback does not overwrite prior website selections. The site is public (noindex is not privacy). Do not include private information in notes that must travel through public hosting.

Raw model responses, screenshots, and bounded-run cost ledger are in the private project's Obsidian `Research/Logo Exploration/2026-11-10/` folder. API calls totaled about $0.07 according to provider usage. No paid image-generation service was used.
